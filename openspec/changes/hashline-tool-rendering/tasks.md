## 4. Edit diff line-number / anchor label policy

- [x] 4.1 In `diff-parse.ts` `parseCanonicalDiffLine`: when the diff is hashline-annotated — gate = ≥1 line matches the STRICT anchor grammar (hash slot `[ZPMQVRWSNKTXJBYH]{2,4}`, NOT the pre-existing loose `[A-Za-z0-9]+` slot, else ordinary diffs whose content merely contains `NN#ab:`-shaped lines activate the strip) AND no `@@` hunk headers AND no `diff --git`/file headers (upstream emits none, so standard diffs can't trigger the strip) — recognize the upstream removed-line shape with an EXACT-width match `^-<padded NN> {pad}<content>` where `pad = hashLength + 2` is derived from the diff's own added/context anchors (all share one hash length; default 4). NOT a greedy ` {4,6}` range: the pad and real leading indentation are contiguous space runs, and a greedy range strips true indentation from indented removed content (verified: pad 4 + 2-space indent loses the indent). Fall back to the existing plain `-` branch when the exact shape doesn't match. Also recognize the elision shape `^ {n}\.\.\.$` (spaces-only, NO digits — upstream emits `(lineNumWidth + 2)` spaces + `...`; the earlier `␣NN␣...` shape was a transcription error) → meta entry. This fixes the empirically-verified bug: removed lines today fall to the generic `-` branch (`:275`) whose `pushParsedLineEntry` keeps `content: rawLine.slice(1)` — the entire number + padding stays in content (e.g. `content: "21    const value20 = 20;"`), duplicating the gutter number in every layout, ungated by config; whole-file replacements additionally yield `oldLineNumber: null` (context-anchored cursor never seeded); elision lines parse as context entries whose content is leftover spaces + `...`, inflating `stats.context`. Pin real-fixture tests in `tests/tool-diff.test.ts`: context-first diffs, spaces-only elisions, whole-file replacement with `-`-first, indented removed content at hashLength 2 AND 3 (exact-width match preserves true indent), no `@@` header, AND a standard unified diff containing anchor-shaped content lines that must NOT activate the strip
